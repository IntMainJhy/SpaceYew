# SpaceYew documentation / 文档导航

[English project introduction](../README.md) · [中文项目介绍](../README.zh-CN.md)

SpaceYew combines editable developer blog homepages with shared docs, independent AI Skills and useful resources. The code is source-available for reading and study; other use, including deployment, requires written permission under [LICENSE](../LICENSE).

SpaceYew 将可编辑的开发者博客主页与共享文档、独立 AI Skill、实用资源连接起来。源码仅供阅读学习，包括部署在内的其他使用须按 [LICENSE](../LICENSE) 事先取得书面许可。

The current editor uses Anx Portfolio and supports original, English and Chinese profile text. It does not contain a theme picker or static-package uploader. Existing hosting APIs remain supported. Catalog creation actions live in Docs, Skills and Other resources; approved entries automatically share to the community.

当前编辑器使用 Anx Portfolio 布局，支持原文、英文和中文资料，不包含主题选择器或静态网站包上传界面，已有托管 API 继续保留。文档、Skill、其他资源各有发布入口，审核通过后自动分享到社区。

Public registration and production publishing remain gated. Local rule screening is triage, not a compliance certificate. There is no public production demo URL at present. Application data, real résumé sources and user media belong in private storage; macOS and Windows clients are outside this repository.

公网注册和生产投稿仍有限制；本地规则仅作风险初筛，不代表合规认证。目前没有公开生产演示地址。应用数据、真实简历源文件及用户媒体保存在私有存储，macOS、Windows 客户端不属于此仓库。

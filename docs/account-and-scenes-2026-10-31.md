# 2026-10-31 页面场景与统一站长账号

## 布局与独立场景

首页收拢后的玻璃标志以画布视口中心定位。品牌、账号菜单与语言导航只限制可用宽度，不再把标志拉向两组控件之间的空隙；空间不足时缩小，避免覆盖按钮。页头与字体尺寸变化也会重新测量。

社区网格恢复为导航、正文、发现三列，明确每个直接子项的位置。两侧吸顶距页顶 106px，短窗口只滚动导航链接或发现栏，账号菜单保留展开空间；平板隐藏发现栏，手机继续使用底部导航。

内页采用三个原创 Blender 模型，保持蓝冰玻璃材质，中央留给内容：

| 页面 | 模型 | 构图 |
| --- | --- | --- |
| 社区及成员页 | `spaceyew-community.glb` | 两片相遇的玻璃弧 |
| 资源、文档、Skill | `spaceyew-resources.glb` | 三片错层玻璃书页 |
| 登录、注册、找回密码 | `spaceyew-login.glb` | 薄壁玻璃门拱 |

建模脚本是 `scripts/build-interior-glass.py`，可用本机 Blender 重新生成 GLB；可编辑 `.blend` 源文件不进入网站仓库。模型均小于 110KB，使用真实玻璃体积与 PBR 透射，独立内页渲染器不加载首页标志模型。渲染只响应指针、滚动及尺寸变化，闲置时休眠；手机降低像素预算，减少动态偏好保持静止，加载失败时保留 CSS 降级。

## 唯一管理身份

私有数据库中的 `ownerAccount` 配置绑定现有账号的 ID 与已验证邮箱：

```json
{"id":"existing-verified-account-id","email":"owner@example.com"}
```

绑定账号还须为正常状态且数据库角色为 `owner`。配置存在但无效时关闭管理权限，不回退旧管理员。真实身份、密码、配置及迁移备份不进入 Git；密码仅保存加盐哈希。公开徽章 `siteOwnerAccount` 与授权独立，改徽章不会授予后台权限。

启用后，只有选定账号可访问管理页及管理 API；旧管理员会话/凭据不再有效，其他 owner/reviewer 对当前站点只具有普通成员权限。平台和独立管理站的原有域与会话隔离仍保留，不声明跨域单点登录。

“我的账号”整合账号安全、个人博客与管理中心，后台可返回账号页。选中账号沿用已有 ID、空间和文件归属；站长发布自己的博客生成固定快照，不覆盖旧站点资料与既有公开链接。目录在选中账号拥有公开主页时省去重复的旧站长卡片。头像、改密、工具凭据、私有预览均按真实账号 ID 校验，注销、换绑及自降权不能使唯一管理身份失效。

还修复了两条旧身份路径：MCP 幂等缓存返回前先验证当前权限；私有网站预览同时核验会话 realm、认证方式与当前有效角色。

## 验证

- 274 项单元测试通过，包含居中、模型及路由、唯一身份、失效身份、账号归属、工具缓存、私有预览和非本机作者资格回归。
- 类型检查（含未使用声明规则）与生产构建通过。
- 稳定隔离副本中的 18 组 HTTP 回归均通过。
- 定向 HTTP 脚本 `node test/owner-account-http.mjs` 使用临时数据库与示例账号，验证统一登录、账号页/后台/个人博客及非站长拒绝。
- 常规 HTTP 回归覆盖身份、CSRF、文件、博客、简历、目录、注册、分站登录、多语言和发布审核。大流量只读检查使用独立临时服务，避免与浏览器验收叠加触发每分钟请求限额。
- 桌面、短窗口、平板及 390px 手机检查：收拢标志居中、社区滚动无重复侧栏，三个内页模型均为实际 WebGL 加载，无破图或横向溢出。

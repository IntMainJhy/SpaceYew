# 2026-10-31 后台功能链核查

本次核查从后台入口、页面控件、调用 API 追到实际读写实现。不读取真实数据库、密码或用户文件；无数据的真实功能不视为空壳。

## 移除的无效界面

| 控件 | 核查证据 | 处理 |
| --- | --- | --- |
| 网站名称、网站简介、默认分享摘要 | `saveConfiguration('site')` 保存这些值，但前台品牌固定为 SpaceYew；`page.tsx` 的 `generateMetadata` 从路由、翻译及公开内容生成标题与摘要，没有读取 `site.name`、`site.tagline`、`site.description` | 移除输入；保存设置仍保留既有值，不修改存储或兼容 API |
| 顶部推广条编辑器 | 公开推广条组件已退役，`promotionBar` 只有存储、校验与兼容读取，没有公开渲染消费者 | 移除启用开关、条目编辑及新增按钮；保留已有配置和 API 校验 |
| 创建一次性邀请 | 当前注册为邮箱验证码注册，登录/注册组件不接收邀请码输入、状态或查询参数；后台生成后的 `/join` 链接也不携带 token | 移除创建表单；既有记录和撤销操作保留，兼容注册 API 不变 |
| 唯一站长模式的「分配社区角色」 | 管理权来自绑定的唯一账号，其他 owner/reviewer 在该模式下均为普通成员；存储 reviewer 角色不能授予后台权限 | 仅在唯一站长模式隐藏该动作；未配置的兼容模式保留实际有效的授权 UI |
| 当前站长自己的账号治理表单 | 后端明确拒绝在账号治理接口修改当前站长身份，所有治理动作都会返回 403 | 改为「我的账号」入口；其他成员的资格、状态与头像治理保留 |

设置保存只覆盖仍可编辑的封面、PDF 和下载配置，未显示的旧字段沿用当前服务器值，避免浏览器旧草稿中的空网站名造成无法保存。

默认分享封面仍由 `generateMetadata` 用于 Open Graph 图片回退，因此保留。附加 PDF 由求职展示页使用，桌面下载配置由下载页和系统下载判定使用，也保留。

## 保留的真实功能

- 项目、文章、资源的编辑、预览、发布、下架及回收站：`/api/admin/content` 与公开内容读取。
- 本人博客编辑与审核、个人资料及经历、分类标签、全局文件与分片续传：相应博客、配置、文件及上传 API。
- 日期筛选、访问/下载统计及文件响应流量：`/api/admin/statistics`；空数据仍会保留其查询能力。
- 投稿/主页/目录/评论审核、举报投诉、成员状态与发布资格、审计日志：真实固定版本和授权 API，不删除安全或审计能力。
- 服务配置状态：邮件、社区开关及安装包链接均来自真实配置；不把「未配置」状态当作不存在的功能。

# 编辑自己的博客主页

[English](blog-editor.md)

`/blogs` 始终展示站长已公开的主页。点击「创建 / 编辑我的博客」进入 `/workspace/blog`，使用网站真实账号登录。新成员仅带入自己的昵称，正文为空，不会复制站长的简历或私有文件。

当前编辑器使用 Anx Portfolio 排版，包含四个栏目：

- **个人资料**：姓名、简介、关于我、头像、可选横幅、技能、公开邮箱、GitHub 和联系链接。可选主页标题与副标题优先于姓名和一句话介绍。
- **经历与作品**：从简历提取可检查的草稿；新增、编辑、排序、移除数字亮点、栏目和条目。条目支持日期、说明、链接、配图和图注。
- **证书与图片**：替换证书及分享现场图片、调整顺序，并选择单独脱敏的公开 PDF。证书采用桌面三列、手机两列的小尺寸网格，点击可放大，Escape 可关闭。
- **分享与发布**：首次发布前修改地址标识、选择是否在平台中被发现、查看审核反馈、撤回待审版本或暂时下线。审核通过后分享稳定的 `/blog/<handle>` 地址。

通过「编辑文字版本」分别填写原文、英文和中文；各语言共用图片及排列，未填翻译使用原文。简历导入不自动翻译或核验事实，须自行核对并删除隐私信息。原始简历不会自动成为公开下载附件。

「保存草稿」只更新私人草稿，「预览草稿」展示当前编辑内容。「提交发布」固定一份版本供审核，后续修改不影响已公开版本。其他标签页更新后会返回冲突提示，避免静默覆盖。引用文件须属于自己的账号，仅随相应审核通过版本公开；下线后停止公开其空间文件。

站长在「管理后台 → 博客主页」（`/admin/blog`）使用管理会话编辑默认主页。明确标记的「保存并公开主页」立即更新站长公开资料并记录审计；普通成员不可调用该管理接口。

私人博客与简历上传只允许真实密码认证的账号使用，演示免登录和体验登录已移除。当前仍限已核查的本地测试账号提交发布，本次变更不会开启公网注册或正式托管。既有静态托管 API 和已审核的网站继续兼容。

个人图片与已填写的主页保留在应用私有存储和备份，仓库仅包含可复用编辑器及测试。

## 默认公开主页

`/blogs`、页面分享元数据和网站首页预览使用同一个公开主页选择。运维可在私有 `featuredBlog` 配置中设置 `{"handle":"public-handle"}`，未设置时仍展示原站长主页。指定主页不会授予编辑权限，也不会绕过审核或下架限制。详见[社区收尾记录](community-finish-2026-10-22.md)。

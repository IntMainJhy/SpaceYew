# 编辑自己的博客主页

[English](blog-editor.md)

`/blogs` 打开已配置的公开主页，默认是站长主页。「创建 / 编辑我的博客」进入 `/workspace/blog`，编辑当前登录成员自己的内容。新成员仅带入昵称，正文为空；已有资料、证书、图片、PDF 和翻译继续保留。

编辑器是基于 MIT React Flow 的博客页面设计器。现有 Anx 主页作为默认模板：直接点文字修改、拖栏目标签移动、从边角调整宽度，也可加入文字、图片和链接。左侧为图层与插入工具，右侧修改位置、颜色、间距和字体。可使用默认模板或从空白开始，内容与排版操作均可撤销、重做。设计随草稿保存，预览与审核后的公开页使用同一个渲染组件；桌面展示保存的布局，窄屏按视觉阅读顺序自动排列。

直接编辑姓名、介绍、技能、数字亮点、简历栏目、条目与公开联系方式。媒体面板可上传、更换头像、横幅、条目配图、证书及现场照片，并单独选择脱敏 PDF 供公开下载。简历先导入可核对草稿，应用前自行核验事实、删除隐私；原始简历保持私有。「编辑文字版本」切换原文、英文和中文；图片、坐标与栏目顺序共用，未填翻译使用原文。

「保存草稿」保存私人修改及卡片坐标，博客需要手动保存。「提交发布」在明确确认发布条款后固定版本供审核，之后修改不影响已批准的公开版本。并发修改返回冲突提示。审核通过后分享稳定的 `/blog/<handle>` 地址；发布面板还提供地址标识、发现设置、审核反馈、撤回和下线操作。下线后停止公开该空间拥有的文件。

私人空间和简历上传要求真实密码认证。文件及引用按账号隔离，公开投稿仍需独立核验真实身份、发布资格并执行服务端审核。生产账号及社区入口依赖运维显式配置的 HTTPS 部署；编辑器变更不代表完成部署。既有静态托管 API 与已审核站点继续支持；编辑器没有静态 HTML/ZIP 上传界面或主题选择器。

站长通过「管理后台 → 博客主页」（`/admin/blog`）使用管理会话编辑默认主页。明确标记的「保存并公开」立即更新公开资料并记录审计；普通成员不可调用该接口。

## 社区与栏目发布

原创社区分享只需正文，省略标题和摘要时自动生成；补充资料收在「更多选项」。第三方来源仍须填写出处和授权信息。Skill 与其他资源先填名称及 HTTPS 链接，简介选填；分类、封面、来源与 Skill 使用信息收在「更多选项」。

文档以标题和正文开始。输入 `/` 插入标题、列表、代码、引用、表格或分隔线，也可使用工具栏；仍支持文本、Markdown 和 HTML 导入。具备资格的成员可上传行内图片，图片引用继续检查归属和审核状态。阅读页采用文库、正文、标题目录布局，写作页也有标题目录；窄屏将侧栏收起或隐藏，为正文留出空间。

仅文档草稿在已填写标题、允许编辑时，停止输入 1,600 毫秒后自动保存。保存期间可继续输入，后续修改会保留；新草稿通过 History API 更新地址，不重挂载编辑器。保存不会提交发布或代为同意条款。社区、Skill、资源及博客仍需手动保存。提交仍要求明确同意条款，并执行相同的认证、资格、审核与媒体检查。栏目审核通过后生成一条关联社区动态，修订复用该动态，下架后联动停止公开。

精选 GSAP 使用一个条目汇总八个模块，旧模块地址跳转到汇总页。编辑器不提供实时协作。

## 默认公开主页

`/blogs`、分享元数据和首页预览使用同一公开选择。运维可在私有 `featuredBlog` 配置中设置 `{"handle":"public-handle"}`，未设置时保留站长默认主页；选择不会授予编辑权限或绕过审核、下架检查。独立的私有 `siteOwnerAccount` 配置（`{"id":"member-id"}`）指定站长标识，不授予后台权限。编辑始终进入当前成员自己的空间。详见[社区收尾记录](community-finish-2026-10-22.md)。

个人图片和已填写主页保留在私有应用存储及备份；仓库只包含可复用网站实现与测试。


「预览效果」支持电脑和手机尺寸，包含未保存的修改。点阵仅出现在编辑工作区，可关闭；「整齐排版」按实际内容高度将图层排列为整页宽度。保存成员草稿不会直接公开，原有审核和媒体访问规则继续生效。

切换模板使用画布内确认，并保留个人资料；从预览返回后仍可撤销与重做。自定义元素在编辑和公开页使用相同的字体、行高与颜色规则。

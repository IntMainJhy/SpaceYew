# 博客主页与静态托管

每位成员拥有 `/blog/<handle>` 形式的固定博客地址，可以选择内置主题，也可以上传自己做好的静态网站。两种方式共用账号隔离、审核记录、举报和下架流程。

## 内置主题

目前提供「Anx Portfolio」「像素手记」「远景日记」「叙事杂志」「简洁档案」「开发者」六种风格。资料、技能、经历、作品、文章和链接来自成员自己的内容；空栏目自动隐藏。封面、头像只能选择自己的文件。保存仅更新草稿，审核通过后才会发布固定版本。

「像素手记」参考 [Anx 的个人网站](https://github.com/AnxForever/anx-portfolio) 的像素签名和细线排版；「远景日记」参考 [Fuwari](https://github.com/saicaca/fuwari) 的宽幅封面、侧栏名片和深色阅读卡片。两个参考仓库都采用 MIT 许可。这两款 SpaceYew 主题为独立实现，没有复制上游代码、品牌、头像或插画。默认风景使用项目已有的原创 AI 示例图片，页面明确标注；成员可以换成自己的封面。主题不会虚构 GitHub 贡献记录或个人信息。

## 使用 Anx Portfolio

这是基于 [anx-portfolio](https://github.com/AnxForever/anx-portfolio/tree/a7434847797658402d50fba29827eef246102bb7) 实际源码适配的第六款内置模板，保留立体像素签名、头像与标题网格、细线分区和作品布局。原作者的品牌、头像和个人资料已移除；签名根据成员的公开用户名生成。不会伪造认证、GitHub 贡献热力图、统计或第三方评价。

1. 打开“博客主页” → “使用 Anx Portfolio 模板”，或直接进入 `/workspace/blog?template=anx`。未登录时先登录，返回后保留模板选择；仅选择草稿，不会自动覆盖公开主页。
2. 在“资料与经历”填写自己的昵称、头像、介绍、公开联系方式和经历，在“内容库”管理可选的作品、文章与资源。空栏目自动隐藏。
3. 回到“主页设置”，检查桌面和手机预览，保存草稿并确认发布权利，再提交审核。
4. 审核通过后，访问 `/blog/<handle>`，通过“分享”复制公开链接、调用系统分享或生成二维码。后续更新沿用同一地址，审核期间旧版继续展示；下架后不可公开访问。

内置模板无需安装依赖、配置 GitHub 或自行构建，每位成员都可独立使用，并继续使用既有账号、存储与审核隔离。适配范围是个人介绍、技能、经历和可选内容，不包括上游 GitHub 接口、搜索、广告、赞助和站点管理服务。

若你已修改原始 Anx 仓库：它目前是 Next.js 服务端项目，不能直接把 GitHub 源码 ZIP 上传。请使用内置适配版，或自行完成静态导出和兼容性调整后，再按下方方式上传。SpaceYew 不执行任意用户仓库的安装或服务端程序。

改编代码保留 [MIT 许可](licenses/anx-portfolio-MIT.txt) 与 [品牌政策](licenses/anx-portfolio-BRAND.md)；本仓库自身的限制性许可不覆盖这些第三方权利。

## 托管现有网站

1. 在自己的电脑上完成网站构建。Astro、Vite 等项目按项目文档运行构建命令。上传构建后的静态文件，不能上传源码、依赖目录、密钥或环境变量。
2. 单页支持 `.html`、`.htm`，最大 5 MiB；多文件网站使用 ZIP，压缩后不超过 25 MiB，解压后不超过 50 MiB。需要包含 `index.html` 或 `index.htm`，以及 CSS、JavaScript、图片和字体。只有一层外部构建目录的 ZIP 也可导入。
3. 资源和页面链接使用相对路径。外部脚本、字体在许可允许时一并打包。提交前在隔离预览中检查所有页面和手机布局。
4. 保存并确认内容发布权利，然后提交审核。审核期间当前公开版本不变，通过后固定博客地址切换到新版本，可以分享链接和二维码。

编辑器提供简约、深色两款独立 HTML 模板，包含中文和英文版本。下载后修改文字、配色，在本机打开检查，再上传即可。模板无需外部脚本、字体、图片或 API。

平台不执行用户的构建命令或后端程序，不支持服务端渲染、接口请求、外部脚本、嵌套页面、表单、Service Worker，以及依赖同源权限的 Cookie／存储。Astro、Fuwari、Next、Vite 的导出网站不能保证原样导入即可运行：绝对路径、运行时接口和搜索服务可能需要调整，请以隔离预览结果为准。

## 隔离与正式部署

上传的网站在不授予同源权限的沙箱 iframe 中运行。CSP 禁止接口请求、表单、Worker 和嵌套页面，脚本限于包内文件与内联代码。直接打开公开 HTML 会回到平台包装页。点击站内外部链接时，由平台包装页展示目标地址，访客确认点击后再打开；上传网站本身不会获得弹窗或顶层导航权限。私有预览链接短期有效，并绑定仍有效的账号会话。导入时检查路径穿越、符号链接、服务端可执行文件及压缩包限制。

每个账号具有 1 GB 存储额度，最多保留 20 个导入版本，原始压缩包与解压文件都计算存储。静态托管不绕过审核、账号资格或投诉处理。当前仓库仍是本地测试实现，不能据此认定已具备中国区公开运营资质。正式上线前应采用独立用户内容域名与对象存储／CDN，完成身份核验、审核运营、备份及滥用处理，并依据实际部署检查 CSP 与浏览器隔离。

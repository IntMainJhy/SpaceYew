# 首页背景版本

2026-10-31，按用户要求恢复蓝色玻璃首页。随后基于蓝色版本迭代为居中的光学摄影棚，加入反射、透射、色散近似与光线编排。最新版本按用户修正：首页导航保留为透明叠层，推荐条不占据首屏；顶部深蓝经过明亮蓝色，沿文档连续过渡到浅冰蓝。原生玻璃模型不变，取消额外折射模糊，提高渲染清晰度，并保留采样与帧调度优化；REA研究与实现边界见 [Lusion光学研究](lusion-optics-study.md)。归档版本 `76eee6c30841e122694c1bf1e4b57ce4f9e12849` 继续作为旧蓝色布局的回退基线。

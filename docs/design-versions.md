新版本首页的“月球 / 玻璃”按钮可直接对比背景，不会跳转或修改已发布的作品。地址也可分享：

- 月球：`/?scene=moon`（默认）。
- 玻璃：`/?scene=glass`。

玻璃切换保留原有模型与渲染器；旧网站代码仍以归档标签为准。切换会释放旧场景的资源、取消未完成加载，静止时停止重绘；减少动态效果偏好下保留静态背景。月球纹理无法加载或 WebGL 不可用时显示同一 Blender 模型的透明渲染图。

月球只导出已确认的天体，不包含材质评审图中的窗框。真实地形、NASA 月面颜色与烘焙法线保留在自包含 GLB 内，来源与衍生说明见 [NASA Moon 署名](licenses/NASA-MOON.md)。网页使用同源资源，不会在运行时请求 NASA 或其他素材网站。

上传仓库存档不代表正式部署；本次预览运行在本机。

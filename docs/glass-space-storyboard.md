# SpaceYew 玻璃空间分镜与页面关系

2026-10-31，基于已有蓝色原生玻璃世界扩展公共平台。网站使用一个明亮的玻璃外观，移除平台深色/跟随系统开关；作者自己选择的博客主题、字体与页面几何仍独立保存。

## 首页

| 滚动位置 | 镜头和模型 | 内容 |
| --- | --- | --- |
| 0–0.2屏 | 原生双折面玻璃围住首屏，鼠标轻微环视 | 居中介绍和实际入口 |
| 0.2–1.3屏 | 玻璃缩小、后退、合拢并上收 | 展板由玻璃薄片弯曲展开衔接 |
| 1.3屏以后 | 小型玻璃标记停在导航空隙 | 作品和创作者列表沿连续冰蓝背景进入 |

展开效果由同一Three.js画布中的真实分段曲面完成，最多同时两块；正文保持正常HTML，使用同一个滚动进度轻微展开，不将正文变成低分辨率图片。导航固定在窗口顶部，背景模糊通过渐变遮罩逐渐减弱，不切成一块白底。收拢完成后，同一个画布接到内容上层，玻璃后方的接收面只在最终画面透明；透射采样仍保留摄影棚。小型原生玻璃标记约48px高，停靠在品牌与导航操作之间的实测空隙；最终透明度0.55，叠在导航模糊层上方保持清晰，避免覆盖作品。内容和后续展开曲面仍清晰可见，不增加第二个渲染器。

## 博客空间

`/blogs`现在是公开空间目录，有独立标题和canonical；不再根据登录者或默认作者替换整页。原有`/blog/:handle`永久地址、公开资格、审核快照、静态网站沙箱和分享规则保留。

分镜为：远处玻璃页面进入 → 镜头穿过页面 → 页面从两侧掠过 → 到达完整空间目录。原生滚动驱动镜头，可以直接跳过进入目录，也可点击当前玻璃打开对应博客。场景取前8个符合公开条件的空间作飞行预览，全部可发现空间仍以可访问HTML目录列出。

模型由已安装Blender原生生成：`scripts/build-blog-glass.py`产生带真实厚度、0.10倒角、8段细分和法线的玻璃页面（保留0.04侧边，避免倒角薄面重叠），导出`public/models/spaceyew-blog-panel.glb`。可编辑`.blend`源在网站Git之外的本地设计档案保留。页面正面的高分辨率显示层包含真实公开名字、简介、头像与封面，直接输出清晰内容；原生玻璃使用正面渲染，避免双面背部进入透射缓冲；圆角由真实几何与MSAA抗锯齿形成，取消透明贴图裁切造成的虚线。边缘独立保留透射、反射与色散，避免正文经过低分辨率透射缓冲和物理材质的mip滤波后变糊。不加载私有草稿，不执行嵌套博客iframe。恢复原有5控制点摄影棚光线，并加上画外延长端点，避免光线在视口内突然截断；放在全部页面后方，并按页面数量保持开场比例。飞行画布从视口顶部铺满到透明导航后方，导航高度只参与保持原有镜头时序，不再形成顶端画面接缝。

## 导航与资源

公共导航为：首页、社区、博客空间、资源。资源中心通过分类切换文档、Skill及其他资源；已有`/docs`、`/skills`及详情/投稿地址保持有效，顶栏统一选中“资源”。社区与编辑器使用同一玻璃色彩、薄片层级和导航语言，现有关注、收藏、投稿、审核、保存、发布等接口不变。

## 动态与性能边界

首页、博客空间入口、其他平台页面各使用自己的单个WebGL画布，不重复叠加背景渲染器。原生滚动保留，不拦截滚轮。博客飞行以120Hz及以上为目标，交互时跟随requestAnimationFrame与显示刷新率，不再限制30fps；主画布采用桌面300万、手机150万像素预算，DPR最多2，保留原始内容贴图与MSAA。玻璃透射源保留桌面70%、手机55%的边长分辨率；固定Three.js r187的基底LOD采样与自动mipmap关闭成对启用，避免逐帧生成未使用的整条mipmap，保留原生反射与RGB色散。静止时停止请求帧，隐藏、离屏和打印时暂停；减少动态效果时提供静态主体和可访问内容，WebGL失败仍可浏览目录与操作页面。玻璃使用Three.js RGB色散近似，接收面的焦散是艺术化近似；不宣称完整光线追踪或所有设备的固定帧率。

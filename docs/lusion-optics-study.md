# Lusion 公开前端研究与 SpaceYew 光学场景

2026-10-31，按用户要求使用 REA 学习 [Lusion About](https://lusion.co/about) 的公开前端，再改进 SpaceYew 的原生蓝色玻璃首页。未将对方模型、贴图或脚本复制到网站资源中。

## 研究方法与证据边界

当前会话未注册 REA MCP 工具；使用已安装 skill 指定的 CLI 回退，从网站项目之外运行 `npx -y rea-agents@latest analyze-javascript-application <captured-tree> --json`。输入来自页面直接引用的[第一方发布脚本](https://lusion.co/_astro/hoisted.CUO_IjfL.js)，1,251,728字节，SHA-256 `b453312bc9b3ae3bdd64b4e57231ed06cd2cef222a26379288925afb4ae57a37`。

首次分析访问269,557个AST节点，达到每文件20,000条语义保留上限。随后按原始AST字符范围原样提取About、后期处理、App三组相关语句，聚焦分析17,943个节点、0语法失败、0语义记录省略；仍有4,475个动态/外部绑定unknown。完整Evidence、来源映射与原始发布包只保留在网站Git之外的本地研究档案。静态代码中存在某个分支，不单独证明它在当前设备上执行。

## 当前首页变化

主标题、CTA、CreatorStage和各节标题沿同一中轴；真实发布内容、链接、语言与外观选择继续使用既有数据。蓝色背景贯穿整页，移除原先CSS、Three背景和Canvas透明度三重向浅白收尾的逻辑。

原生模型保持不变。玻璃使用IOR1.48、厚度0.62、粗糙度0.026及强度1.05的Three.js RGB色散近似；HDR环境由原创程序灯卡与暗旗生成，背景有可被透射采样的蓝色明暗结构。暖色、冰蓝色细光源实际放在玻璃后方，端点延伸到画面之外，独立于玻璃移动，让折射结构相对滑动。手机上将主体肩部安排在首屏操作下方。背景接触暗部和焦散曲线属于艺术化接收面近似，未宣称真实光线追踪焦散。HTML正文不在Three场景中，不会被该透射材质物理折射。

滚动改变镜头深度、玻璃分离度和姿态，持续活动时间驱动灯条反射和轻微浮动。减少动态效果时保留静态构图，交互与内容可访问；WebGL失败时保留同一蓝色CSS背景和全部正文。

# Lusion 公开前端研究与 SpaceYew 光学场景

2026-10-31，按用户要求使用 REA 学习 [Lusion About](https://lusion.co/about) 的公开前端，再改进 SpaceYew 的原生蓝色玻璃首页。未将对方模型、贴图或脚本复制到网站资源中。

## 研究方法与证据边界

当前会话未注册 REA MCP 工具；使用已安装 skill 指定的 CLI 回退，从网站项目之外运行 `npx -y rea-agents@latest analyze-javascript-application <captured-tree> --json`。输入来自页面直接引用的[第一方发布脚本](https://lusion.co/_astro/hoisted.CUO_IjfL.js)，1,251,728字节，SHA-256 `b453312bc9b3ae3bdd64b4e57231ed06cd2cef222a26379288925afb4ae57a37`。

首次分析访问269,557个AST节点，达到每文件20,000条语义保留上限。随后按原始AST字符范围原样提取About、后期处理、App三组相关语句，聚焦分析17,943个节点、0语法失败、0语义记录省略；仍有4,475个动态/外部绑定unknown。完整Evidence、来源映射与原始发布包只保留在网站Git之外的本地研究档案。静态代码中存在某个分支，不单独证明它在当前设备上执行。

## 当前首页变化

主标题、CTA、CreatorStage和各节标题沿同一中轴；真实发布内容、链接与语言继续使用既有数据。首页导航透明叠在场景上，保留导航与语言操作，平台深色/系统外观切换已按后续要求移除，推荐条不占据首屏。按用户最新修正，深蓝、亮蓝、浅冰蓝沿文档连续渐变，CSS与WebGL使用相同颜色锚点；开场与内部页面保留不透明的摄影棚接收面；首页收拢完成时，接收面仅在最终画布渐隐，透射目标仍保持不透明。同一画布中的小型玻璃停靠导航空隙，CSS连续背景承接阅读区域，避免被卡片遮住或突然切换白底。

原生模型保持不变。玻璃使用IOR1.52、厚度0.85、粗糙度0.01及强度1.4的Three.js RGB色散近似，去掉清漆层和额外环境模糊；HDR环境由原创程序灯卡与蓝灰暗旗生成，采用更宽的主光和较窄的轮廓光，控制浓蓝吸收与泛白。背景有可被透射采样的明暗结构。暖色、冰蓝色细光源实际放在玻璃后方，端点延伸到画面之外，独立于玻璃移动，让折射结构相对滑动。手机上将主体肩部安排在首屏操作下方。背景接触暗部和焦散曲线属于艺术化接收面近似，未宣称真实光线追踪焦散。HTML正文不在Three场景中，不会被该透射材质物理折射。

背景接收面、玻璃和实景细光源采用一致的直接输出，避免只对透射结果应用ACES而令浅色背景经玻璃后变灰。玻璃表面基色保持中性，冰蓝只由体积衰减提供；局部高亮可能裁切，但不以全局曝光或模糊掩盖透射明暗不一致。

后续交互扩展将滚动改为双折面玻璃缩小、后退、合拢并上收，推进文档渐变背景；分段曲面承接正文展开，完整分镜见[玻璃空间分镜](glass-space-storyboard.md)。持续活动时间驱动灯条反射和轻微浮动。减少动态效果时保留静态主体构图，交互与内容可访问；WebGL失败时保留同一渐变CSS背景和全部正文。

## 实时渲染取舍

保留Three.js物理玻璃的厚度、IOR和RGB折射射线，在固定r187版本中局部将透射纹理的双三次重建改为线性mip采样，使RGB路径从24次纹理读取降为3次；取舍是低粗糙度折射背景的滤波细节。补丁只在版本、原始chunk和include均精确匹配时生效，否则保留标准材质，不修改共享ShaderChunk。取消人为LOD模糊下限，透射目标比例提高到桌面0.7、手机0.55，主画布按总像素预算限制，优先保留清晰边缘。

帧调度保留截止时间余数，避免60Hz下的浮点边界漏帧；操作时最多30fps，空闲光线变化最多15fps。可见动画时钟与指针阻尼分开累计，持续掉帧会降低像素密度。移除展板的实时背景模糊，并避免仅DPR变化时重建光源几何。这些是源码确认的成本控制，不代表所有设备的实测帧率保证。

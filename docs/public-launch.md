# 公开部署与运营边界

[English](public-launch.en.md) | **简体中文**

代码支持显式开放生产账号和社区；部署不是合规认证，也不自动取得任何行政许可。只有实际满足相应要求的运营者，才能按自身服务范围开放有关功能。

## 技术启用

依照[双入口部署](../deploy/README-split.md)配置真实 HTTPS 域名、独立平台/后台进程、共享私有数据、可信反向代理和强管理员密码。两个进程设置 `PUBLIC_FEATURES_ENABLED=true`；平台另设 `REGISTRATION_ENABLED=true` 开启邮箱注册。缺省仍关闭公网功能，不伪装 localhost。

在私有环境文件配置 `LEGAL_OPERATOR`、`LEGAL_CONTACT_EMAIL`、`LEGAL_EFFECTIVE_DATE`，可补充 `LEGAL_ADDRESS`。公开政策从实际运营信息生成；缺少必要配置时不能注册或提交。确认记录保存所阅读政策的版本和全文哈希，不能使用本地草案的同意记录替代生产政策确认。邮件必须使用真实 SMTP；capture 只在本机生效。

## 账号、草稿与公开发布

邮箱验证码仅验证邮箱控制权。新账号可以登录、编辑自己的私有草稿；不自动取得公开发文、评论、头像或博客发布资格。历史 `local_test` 仅在本机有效。站长蓝色标志不赋予管理员权限或实名核验状态。

公网发布需要账号正常、`verification=verified`，并继续通过内容审核、来源/许可、冻结和版本检查。管理员的“记录身份核验”操作要求已实际完成的昵称审核和身份核验、核验方式及可追溯凭证索引，记录操作人和时间；该按钮不执行外部身份核验，不得以勾选代替核验事实。不要把原始证件号码放入普通审核备注。

当前仓库不附带短信/实名认证供应商、身份证数据库或 IP 地理数据库。运营者必须自行配置合法、适用的身份核验方式，并在处理前告知信息类别、用途及提供方。依法需要的账号 IP 属地展示尚需接入真实可靠的属地来源，不能凭邮箱或服务器所在地推断。**这些条件未落实时，不要为普通用户授予公网发布资格。** 已审站长主页可以保留公开阅读，不能借此提交未经核验的新版本。

## 内容治理

手动社区投稿与文档/Skill/资源自动分享使用同一治理边界。低风险文字可按规则自动通过；风险词、外链、图片和安装命令等待人工核查，静态博客人工审核。词表不是语义 AI 审核，也不能穷尽违法内容；需要巡查、举报、应急处置及适当人员投入。账号或关联工单受限时，原文与同步分享停止公开。

公开提供无需登录的举报/权利投诉入口和运营联系渠道，及时受理、甄别、处理及反馈；保留必要审计依据。适用专项资质、新功能安全评估、备案范围及其他治理要求，应按实际业务核查，不因具备 ICP 编号而假定所有社区服务均可开放。

## 运营维护

生产数据和邮件配置不进入 Git。通过一致备份迁移数据库和全部登记文件；恢复撤销原会话、验证码和工具令牌。上公网前更换旧弱管理员凭据。每日运行 `scripts/cleanup.mjs`，安排独立私有备份及实际恢复验证，为安全日志设置适用的受限保存和轮转流程；不要删除依法应保留的投诉和安全记录。

上线检查覆盖证书续期、SMTP 实际投递、成员与后台会话隔离、跨账号草稿/媒体访问、手动投稿、目录同步去重、风险审核、举报、冻结和重启恢复。不得把测试账号或测试帖写入生产库。

参考：[互联网用户账号信息管理规定](https://www.cac.gov.cn/2022-06/26/c_1657868775042841.htm)第九条与第十二条、[互联网跟帖评论服务管理规定](https://www.cac.gov.cn/2022-11/16/c_1670253725725039.htm)第四条、[非经营性互联网信息服务备案管理办法](https://www.miit.gov.cn/zcfg/xxtxl/art/2024/art_7e48434c08c24131b4b7eecfca5b2b6c.html)第十三条。具体适用性应由运营者结合实际业务核查。

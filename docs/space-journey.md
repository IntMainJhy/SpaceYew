# 首页太空漫游

默认首页和 `/?scene=space` 使用同一条太空航线。`/?scene=moon` 保留已认可的独立月球版，`/?scene=glass` 保留归档玻璃版；切换保留其他查询参数、锚点和 Next.js history 状态。

## 原生模型与网页渲染

银河的21,000个原始顶点、三种烘焙PBR小行星网格和月球均来自可编辑 Blender 工程。网页直接读取导出的银河点位置、颜色与尺寸属性，用着色器呈现柔和星点；桌面显示42颗共享网格的岩体，手机显示20颗、8,000个银河点。月面沿用已认可的NASA/LRO纹理、地形及法线。完整来源见 [SPACE-SCENE.md](licenses/SPACE-SCENE.md) 和 [NASA-MOON.md](licenses/NASA-MOON.md)。

相机沿单调、连续的一条空间曲线从Z=100前进到Z=-2，月球固定在(8,-1,-22)，而不是放大一张背景图片。手机保留相同位置路径，以独立的取景目标和视角呈现近景。

## 操作

- 原生滚动控制远观银河、穿越岩带和抵近月面三幕；支持反向返回。
- 桌面鼠标轻微环视，按住拖动可扩大观察角度；包含轻微环视在内的总角度限制为6°/3°，抵近时收窄。
- 中段点击实际岩体，通过射线拾取进入观察；“观察小行星”提供键盘入口。按Esc、点空白、“返回航线”或继续滚动退出。拖动不会误触点选。
- 首次越过中段阈值出现一条彗星，随后按活动时间间隔出现；同时最多一条。后台、离屏、打印和观察岩体时暂停。
- 底部可直接跳过漫游；主CTA仍然直达真实公开主页列表。

## 生命周期与内容

场景容器桌面430svh、手机340svh，进度按容器实际可滚动距离归一化。介绍文字退出后同步inert和aria-hidden，回滚、切换、打印及清理时恢复。CreatorStage位于旅程之后，作品与主页内容继续来自既有数据；卡片使用CSS视图时间线，在不支持该特性的浏览器保持可见。

加载期间、模型/WebGL失败及降动效模式均保持约一屏介绍，不留数屏空白。异步加载完成时若访客已经离开首屏，不扩展旅程推走正文；可显式重新进入。失败提示可继续访问后续内容。

渲染上限30fps，DPR桌面1.5/手机1.25。活动时钟只在实际可见帧中推进，后台恢复不追赶动画；离开旅程停止GPU循环，保留最后画面接续内容区。场景切换、卸载和上下文丢失释放加载、事件、纹理和GPU资源。

## 参考边界

参考 [Ego Lite](https://lite.ego.app/) 的大主体、留白和滚动层次关系。参数、原生模型、镜头和交互由本项目重新设计；未复制参考站资源，未将视觉观察推断为其内部源码实现。

## 验证

`npm test` 包含镜头连续性、安全距离、手机投影、活动时钟、降动效、拖动/点击区分、清理和三场景切换检查。另运行类型检查、生产构建、首页HTTP和安全集成。浏览器验收覆盖1440×900、390×844、2048×1056；实际滚动、触屏滑动、拖拽、聚焦和彗星需结合运行画面验收，单元测试不替代浏览器检查。

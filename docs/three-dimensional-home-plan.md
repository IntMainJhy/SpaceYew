# SpaceYew 3D 首页重构 · 第一阶段规划

> 2026-11-01 更新：已采用概念 A「一页之间」，首页排版采用居中式 B。实现见 `src/lib/home-glass.ts`、`src/app/three-home.css`、`scripts/build-home-page.py`。

- 日期：2026-11-01
- 分支：`codex/three-dimensional-home`
- 范围：分析与规划，不改运行代码
- 参考：[Ego Lite](https://lite.ego.app/)、[Lusion About](https://lusion.co/about)

## 0. 结论先行

现状不是单一配色问题。首页的**背景光**、**3D 物体**、**DOM 表面**是三套互不相干的语言：

1. 背景是一条与视口无关的线性蓝色渐变，CSS 一套、WebGL 着色器另一套。
2. 3D 是两个镜像的平直玻璃框，完整入画、对称悬浮，更像装饰画框而不是空间。
3. 内容层是 macOS 窗口、白色卡片、深色标题块、灰色工具条混用，半径与阴影不统一。

建议的方向：**一个不对称、被画面裁切的玻璃主体 + 一套摄影棚光场 + 一条滚动时间轴**。3D 状态跟随内容章节变化，而不是四个相同的左右图文块。先重构首页，其余页面按层级对齐，不动业务逻辑。

主概念有 A / B / C 三个方向，推荐 **A「一页之间」**，需要你确认后再进入第二阶段。

## 1. 现状诊断

### 1.1 背景配色

当前实际使用的颜色与来源：

| 位置 | 值 | 观察 |
| --- | --- | --- |
| WebGL 接收面顶部 | `#070f29` | 深海军蓝，方向正确 |
| WebGL 接收面中段 | `#1858c9` | 高饱和"默认科技蓝"，占据首屏最大面积 |
| WebGL 接收面下部 | `#d9d9dc` → `#e5e5e5` | 进入中性灰 |
| CSS 首页渐变 | `#142a5d 0` → `#236fde 420px` → `#eef3f9 1040px` | 与 WebGL 颜色锚点不一致 |
| 资源 / 社区页 | 深蓝到饱和蓝的竖向 ramp | 同一套"海报渐变" |

问题：

- **大面积高饱和蓝**。`#1858c9` 色相约 214°、饱和度约 78%，几乎铺满首屏，缺少暗部与中性过渡，视觉上接近通用 SaaS 模板蓝。
- **两套光**。CSS 渐变与 Three.js 接收面各自插值，颜色锚点、明暗结构、出现位置都不同，页面滚动时背景与玻璃不在同一光场里。
- **没有光的方向**。渐变只有上下，没有主光源、地平线、环境遮蔽或颗粒，所以像壁纸，不像空间。
- **底部偏紫**。深蓝直接插值到 `#d9d9dc` 时会经过一段灰紫，配合玻璃的青蓝色反射，整体显"脏"。

### 1.2 建模

现有 GLB 的实际数据（Blender 5.2.3 导入统计）：

| 模型 | 网格 | 三角面 | 尺寸（Blender 单位） | 结构 |
| --- | --- | --- | --- | --- |
| `spaceyew-glass.glb`（首页） | 2 | 2,360 | 1.188 × 0.44 × 2.957 | 两个完全镜像的折面 |
| `spaceyew-blog-panel.glb` | 1 | 972 | 4.8 × 0.24 × 3.15 | 一块平板页 |
| `spaceyew-home-kinetic.glb` | 6 | 16,800 | 弧形 + 节点 | 编织弧形装置 |
| `spaceyew-community.glb` | 2 | 6,280 | 3.32 × 3.29 × 0.22 | 两条薄弧 |
| `spaceyew-login.glb` | 3 | 3,740 | 门框造型 | 拱形门框 |
| `spaceyew-resources.glb` | 3 | 900 | 2.38 × 3.14 × 0.19 | 三块晶片 |

首页模型的问题不在面数，而在造型语言：

- **镜像**。两片逐点对称，`split` 动画也只是沿 X 轴等距分开，天然产生"括号/画框"的读法。
- **平直**。主体是带倒角的平板挤出，没有连续曲率；高光只能落在倒角线上，正面大面积是均匀的浅灰。
- **厚度均一**。没有厚薄变化，缺少玻璃最关键的光程差，色散只存在于很窄的边上。
- **完整入画**。模型被完整收在视口内，没有裁切、没有前后景，观者是在"看一个物体"，而不是"身处一个空间"。
- **没有落地**。物体悬浮，接触阴影是着色器里画的软斑，与真实反射不匹配。

### 1.3 构图与排版

- 首屏 `min-height: 100svh`，标题、副标题、两个按钮全部居中；两片玻璃左右对称围住文字。
- 结果是**静态的对称海报**：没有非对称张力，没有大小对比，没有前后层次，第一屏除了文字没有第二个视觉焦点。
- 标题 42–64px、字重 550、居中，信息层级正确，但字号与 3D 主体的比例关系保守，物体没有"压住"版面。
- 首屏以下立刻接真实创作者窗口（macOS 窗口样式），从"空间"掉回"产品截图"，风格断裂。

### 1.4 材质与光

当前材质参数：`transmission 1`、`ior 1.45`、`thickness .46`、`roughness .012`、`dispersion 4.8`、`iridescence .56`。

- 色散值被刻意放大，但平板正面没有曲率，RGB 分离只出现在倒角，观感更像"带彩边的亚克力"。
- 摄影棚由程序化灯卡生成 PMREM，主光 3.3、轮廓光 1.3、补光 0.12，整体偏均匀；玻璃正面缺少明确的明暗分区。
- 没有地面反射与真实接触阴影，玻璃与背景之间没有"空气"。
- 环境强度随滚动在 1.03–1.37 之间变化，但没有与相机、物体、灯光形成统一的曝光故事。

### 1.5 表面系统

`src/app` 下有 56 个 CSS 文件，首页同时叠加 `v2.css`、`glass-studio.css`、`home-showcase.css`、`home-blog-canvas-demo.css`、`product-home.css` 等。实际界面中出现了：

- 16px 圆角浅色卡片、999px 胶囊按钮、深色标题块、灰色工具条、macOS 窗口；
- 同一页里既有半透明玻璃面板，也有不透明纸面；
- 不同面板的内高光、阴影颜色和模糊强度各自定义。

这不是"组件多"，而是**没有统一的表面层级**。新的设计需要先定义 3 种表面（Scenery / Surface / Paper），再让所有组件引用。

### 1.6 动效

- `HomeMotion` 只在区块进入视口时做 32px 位移与透明度入场；`PageMotion` 只做 10px 淡入。
- 首页滚动会驱动玻璃分开、相机后退，但背景、灯光、内容没有共享同一条时间轴。
- 页面首次进入没有编排，第一帧是静止的；参考站的首屏是一个"正在发生"的场景。
- 没有页面切换的空间过渡，导航切换基本是淡入。

### 1.7 工程与内容约束

- 首页内容来自真实公开数据（`defaultBlogSpace`、审核后的作品、隐藏栏目），不能为了视觉补造人物或成绩。
- 单个 Three.js 画布已经承担透射、色散与自定义 shader，移动端像素预算 300 万；新增粒子、后期必须纳入同一预算。
- 仓库有 64 个单元测试文件与多组隔离 HTTP 测试；视觉重构必须保留现有路由、审核、发布与账号流程。
- 许可：站内素材需自制；不复制参考站模型、HDR、发布代码或文案。

## 2. 参考拆解

| 维度 | Ego Lite | Lusion About | 对 SpaceYew 的取舍 |
| --- | --- | --- | --- |
| 主体 | 一个巨大的玻璃穹面，四条边全部超出画面 | 一个密集粒子雕塑，占据上半屏 | 用一个**超出画面**的玻璃主体，而不是两个完整入画的框 |
| 构图 | 文字小、居中，主体就是版面 | 巨型裁切字体压在画面底部，3D 是上半部 | 字体参与构图，但保留 SpaceYew 的可读性与中文排版 |
| 光 | 深海军蓝 → 亮蓝 → 近白的连续光场，一条锐利高光 | 近黑背景 + 体积光 + bloom，明暗对比极强 | 深蓝到冰白的**有方向光场**，暖色只出现在高光 |
| 材质 | 真实 GLB + EXR 环境，IOR / 厚度 / 色散随滚动插值 | 自制 shader 粒子、雾、散射 | 原创 GLB + 自制摄影棚 HDR，不用第三方环境图 |
| 动效 | 阻尼相机、滚动驱动、首屏材质从薄到厚 | 多 canvas 分层、自定义滚动、运动模糊预通道 | 一条滚动时间轴，一个画布，不做多层 canvas |
| 可借鉴 | 尺度与裁切、单主体、克制的 UI | 明暗对比、材质的"贵感"、编辑式排版 | 尺度、裁切、单一光故事、字体与留白 |
| 不复制 | 穹面轮廓、EXR、发布代码 | 粒子爆炸形态、文案与版式 | 保持原创造型与内容 |

**关键判断：** 当前首页"差一点意思"，主要差在**尺度**与**光**，不是差在模型面数。把物体放大到超出画面、让光有方向、让背景有地平线，收益远大于把 2,360 面加到 20 万面。

## 3. 三个概念方向

### A. 一页之间（推荐）

**一句话：** 一张巨大的玻璃页悬在暗色摄影棚里，先以侧边对着你，随着滚动展开成拱形，镜头穿过它进入内容。

- 首屏：玻璃页几乎侧立，只看到一条被照亮的厚边和内部折射；文字在左下，物体从右侧出血。
- 滚动：页面上端向后翻、下端向前卷，形成一道 5–7 米高的拱；镜头推进，穿过玻璃进入浅色内容区。
- 章节：Blog / Community / Resources 分别是这张页的三种状态——平放、叠放、折成棱镜。
- 为什么适合 SpaceYew：产品本身就是"给你的创作一页空间"，造型与叙事直接对应；与 Ego 的穹面、Lusion 的粒子都不同。
- 技术可行性：一条曲线放样 + 实体化 + 倒角即可生成，Blender 脚本可控，面数 6–10 万。
- 风险：侧立时"信息量"低，需要靠边缘高光与内部折射撑住第一印象；必须做 3 个灯光/角度变体渲染对比。

### B. 光之门

**一句话：** 一条扭转的玻璃带在空间中围出一个不规则开口，光从开口后方射入。

- 首屏：开口偏向画面右侧，左缘超出画面；带子的厚度在扭转中变化，边缘出现细窄光谱。
- 滚动：开口逐渐张开，镜头沿开口轴线前进。
- 章节：开口形状随章节变化（矩形 → 圆形 → 网格）。
- 优点：空间感强，容易做出"穿过去"的体验。
- 风险：与"门/拱"的既有首页模型距离较近，容易只是把两个框换成一个框。

### C. 光谱棱镜

**一句话：** 一块巨大的深色玻璃棱镜立在地平线上，一束光穿过它，在前景铺开为光谱带。

- 首屏：棱镜占右侧 2/3，光束从左上方射入，光谱落在左侧文字下方。
- 滚动：棱镜旋转，光谱带扫过页面，章节内容在光谱落点出现。
- 章节：不同章节对应不同波段，但**不使用大面积彩色**，只让光谱出现在边缘与接触面。
- 优点：概念强，视觉记忆点高。
- 风险：容易滑向"彩色渐变"，与"不要廉价发光"的要求冲突；实现上需要真实色散或高质量假色散，移动端成本高。

**推荐 A**：产品相关度最高、与参考站差异最大、资产与性能最可控。B 作为备选，C 暂不建议。

## 7. 技术选型

| 层 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | Next.js 15 App Router + React 19 + TypeScript 5.9 | 保持现状，零迁移成本 |
| 3D | Three.js r187（原生，不使用 R3F 重写主场景） | 现有渲染器、色散与 shader 补丁都在这一层；避免两套运行时 |
| 模型 | Blender 5.2.3 + Python 脚本导出 GLB | 已有同管线；资产可复现 |
| 环境 | 自制 HDR 摄影棚（Blender 渲染，1024×512 EXR） | 原创建模；真实反射优于程序化灯卡 |
| 滚动 | GSAP 3.15 + ScrollTrigger | 已是依赖；用于章节进度、粘性舞台与 DOM 编排 |
| UI 状态动画 | Motion（`motion/react`，按需引入） | 页签、面板、弹层的进入/退出更简洁；用 `LazyMotion` 控制体积 |
| 页面切换 | GSAP + CSS View Transitions（渐进增强） | 支持时做真实的空间过渡，不支持时退化为淡入 |
| 图形降级 | CSS scroll-driven animations | 已在用；作为无 JS / 低端设备的备选 |
| 测试 | `node --test` + 现有 HTTP 脚本 | 增加纯函数场景测试与降级测试 |
| 包体 | 不新增大型 3D 库；Motion 按需加载 | 首屏 JS 预算 ≤ 现有 + 20KB gzip |

**需要你确认的选型点：** 是否允许新增 `motion` 依赖。若不允许，页签与面板动画全部用 GSAP 实现，方案不受影响。

## 8. 视觉设计规范

### 8.1 颜色

设计原则：**大面积只有墨蓝与冰白，彩色只出现在玻璃边缘与高光。**

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ink-1000` | `#04060C` | 顶部最深背景、页脚 |
| `--ink-900` | `#070B14` | 首屏主背景 |
| `--navy-800` | `#0B1830` | 深色面板 |
| `--navy-700` | `#10264A` | 地平线过渡 |
| `--blue-500` | `#2F5BEA` | 主操作、链接 |

**光场规则：**

- 深色区必须有明确光源方向（左上方主光、右侧冷轮廓、地面反弹），不允许四向均匀。
- 从深到浅的过渡只发生一次，且与 3D 接收面共用同一组颜色锚点。
- 禁止在正文区使用大面积渐变；渐变只属于场景。
- 允许 2%–3% 的胶片颗粒，叠加在场景与深色区，抑制色带。

### 8.2 字体

| 角色 | 字体 | 规格 |
| --- | --- | --- |
| Display | Space Grotesk（OFL，新增 1 个可变字体文件） | `clamp(56px, 7vw, 112px)` / 0.95 / -0.045em |
| 中文标题 | 现有 CJK 回退（PingFang SC / Noto Sans SC） | 比拉丁字号小一档，行高 1.05–1.15 |
| Headline | Space Grotesk | `clamp(28px, 3vw, 44px)` / 1.15 |
| 正文 | SpaceYew Sans（现有 DM Sans） | 16px / 1.75 / 字重 400 |
| 标签 | Space Grotesk | 11px / 1.4 / 大写 / 0.12em |
| 数字 | Space Grotesk tabular | 用于统计与序号 |

不引入中文 Web 字体，避免首屏体积；中文继续使用系统字体。若你希望完全不加新字体，可保留 DM Sans，仅调整字号与字距。

### 8.3 网格与间距

- 桌面：12 栏，最大宽度 1520px，页边距 `clamp(20px, 5vw, 96px)`，栏间距 24px。
- 平板：8 栏；手机：4 栏，页边距 20px。
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128 / 160。
- 正文行宽 60–68ch；中文 28–34 字。
- 首屏采用非对称布局：文字占 1–5 栏，3D 主体从第 4 栏出血到画面右缘。

### 8.4 圆角、阴影、边界

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-0` | 0 | 场景接收面、结构线 |
| `--radius-sm` | 8px | 输入框、标签 |
| `--radius-md` | 14px | 浮层卡片 |
| `--radius-pill` | 999px | 仅主按钮与语言切换 |
| `--line-dark` | `rgba(220,233,247,.14)` | 深色区分隔线 |
| `--line-light` | `rgba(11,18,32,.12)` | 浅色区分隔线 |
| `--shadow-float` | `0 1px 0 rgba(255,255,255,.06) inset, 0 30px 80px -40px rgba(0,0,0,.65)` | 场景浮层 |
| `--shadow-paper` | `0 1px 0 rgba(255,255,255,.6) inset, 0 18px 50px -34px rgba(16,38,74,.35)` | 纸面卡片 |

规则：**结构面板用直角或 8px；只有按钮是胶囊。** 不再混用 16px/20px/24px 的卡片圆角。

### 8.5 表面层级

只保留三种表面：

1. **Scenery**：3D 场景与背景，无边框。
2. **Surface**：叠在场景上的半透明面板，`backdrop-filter: blur(18px) saturate(120%)`，1px 内高光，仅用于导航、窗口、浮层。
3. **Paper**：浅色内容区，暖白底、细边界、无模糊，用于正文与目录。

所有组件必须显式声明属于哪一种，禁止第四种。

### 8.6 按钮与控件

- 主按钮：实色 `--blue-500`，白字，48px 高，胶囊；hover 提亮 8%，按下缩放 0.98。
- 次按钮：透明底 + 1px 边界，深色区用冰白描边。
- 文字链接：下划线只在 hover 出现，偏移 5px。
- 焦点：2px `--blue-500` 外框 + 2px 偏移，深色区用 `#BFD6FF`。
- 触控目标不小于 44×44。

### 8.7 内容与图片

- 真实内容优先：创作者、作品、资源均来自现有公开接口。
- 没有封面时用排版生成封面（现有能力），不补造图片。
- 视频只在视口内播放，提供暂停；减少动态时不自动播放。

## 9. 动效规范

### 9.1 时间与曲线

| Token | 值 | 用途 |
| --- | --- | --- |
| `--dur-micro` | 160ms | hover、按下、焦点 |
| `--dur-ui` | 320ms | 页签、面板、菜单 |
| `--dur-reveal` | 720ms | 标题与区块入场 |
| `--dur-scene` | 1200–1600ms | 材质与镜头稳定 |
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | 默认 |
| `--ease-in-out` | `cubic-bezier(.65,0,.35,1)` | 场景位移 |

不使用弹跳、回弹、旋转 360° 等廉价效果。

### 9.2 首屏编排（0–1.6s）

1. 背景光场先亮（0–400ms，透明度 0→1）。
2. 玻璃页从"无厚度"到"有厚度"稳定（300–1600ms，`thickness 0.02→0.06`、`ior 1.3→1.46`）。
3. 眉题（0.2s）→ 主标题逐行遮罩（0.3–0.9s）→ 副标题（0.7s）→ CTA（0.85s）。
4. 滚动提示在 1.4s 淡入。
5. 减少动态：直接显示最终帧，不做材质插值。

### 9.3 滚动时间轴

- 一个 `ScrollTrigger` 驱动全局进度 `p ∈ [0,1]`，传给 Three.js 的 `scene.setProgress(p)`。
- 0–0.2：玻璃页微转，厚边高光扫过。
- 0.2–0.45：页面上端后翻，开口成形；镜头 z 从 8.2 → 6.4。
- 0.45–0.7：镜头穿过开口，背景从墨蓝过渡到纸白。
- 0.7–1：玻璃回到画面边缘，成为章节舞台的前景。
- 所有插值使用阻尼（`damp`），不直接绑定滚动值。

### 9.4 章节舞台

- 三章共用同一画布；章节切换由滚动进度触发，3D 在 600ms 内形变到下一状态。
- DOM 内容用 `clip-path` 遮罩 + 24px 位移进入，80ms 交错。
- 不做全屏 pin 超过 3 屏；移动端取消 pin，改为逐段展示。

### 9.5 页面切换

- 进入：场景先淡入 200ms，内容 320ms 后进入。
- 离开：内容 180ms 淡出，导航指示器先行移动。
- 支持 View Transitions 时，用玻璃边缘作为转场遮罩；不支持时退化为淡入淡出。
- 所有转场尊重 `prefers-reduced-motion`。

### 9.6 指针与相机

- 指针最多影响 2.5° 旋转、0.4% 位移，阻尼系数 7。
- 触摸设备不做指针视差。
- 空闲 2 秒后进入 30fps 的"呼吸"状态；不可见、离屏、打印时停止渲染。

### 10.1 场景图

```
Scene
├─ StudioBackground (ShaderMaterial, 全屏接收面)
│   ├─ 顶部深墨蓝
│   ├─ 地平线暖灰光

├─ KeyLight (Directional, 暖白)
├─ RimLight (Directional, 冷蓝)
└─ Camera (fov 40, 35mm 等效)
```

### 10.2 主模型规格

| 项 | 目标 |
| --- | --- |
| 形态 | 单张连续曲面玻璃页，带 12° 扭转与一道 0.4m 折痕 |
| 尺寸 | 3.2 × 0.06 × 4.6（场景单位），可放大到超出视口 |
| 厚度 | 0.04–0.10 变化（边缘厚、中部薄） |
| 倒角 | 0.012，3 段，抛光 |
| 面数 | 60k–100k 三角面 |
| 法线 | 平滑，保留硬边倒角 |
| 材质 | Principled：transmission 1、IOR 1.46、roughness 0.03、色散由 Three 提供 |
| 导出 | GLB，保留 UV，不烘焙贴图，不压缩 |

### 10.3 摄影棚 HDR

- 在 Blender 中搭建：深蓝环境球、左后上方 4×3m 暖白柔光箱、右侧 0.5×4m 冷光条、纸白地面反弹、两块黑色负补。
- 渲染 1024×512 EXR（或 HDR），PMREM 后释放。
- 素材自制，不下载第三方 HDRI。

### 10.4 光与曝光

- 主光：暖白 `#FFF1DE`，强度 3.0，来自左上后方。
- 轮廓：冷蓝 `#BFD9FF`，强度 1.2，来自右侧。
- 环境：强度 0.9–1.1；地面反弹 0.15。
- 色调映射：ACES Filmic，曝光 1.0；深色区不额外提亮。
- 允许高光裁切在极小面积，不使用全屏泛光掩盖材质。

### 10.5 后期

- 默认：无全屏 Bloom，仅 CSS 颗粒与暗角。
- 可选：半分辨率 Bloom，阈值 0.9、强度 0.18，只在桌面开启。
- 色差：仅玻璃边缘的材质色散，不做全屏 RGB 偏移。

### 10.6 性能预算

| 设备 | DPR 上限 | 像素预算 | 透射分辨率 | 粒子 | 后期 |
| --- | --- | --- | --- | --- | --- |
| 桌面 | 1.75 | 500 万 | 0.6 | 1,200 | 可选 Bloom |
| 平板 | 1.5 | 350 万 | 0.5 | 600 | 无 |
| 手机 | 1.5 | 250 万 | 0.45 | 300 | 无 |

- 掉帧 12 帧后自动降至 0.75 质量；恢复需连续 60 帧稳定。
- `prefers-reduced-motion`、`saveData`、后台、离屏、打印时停止。
- WebGL 失败时保留完整 CSS 渐变与所有文字。

## 11. Blender 资产流程

1. `scripts/build-home-page.py`：曲线放样 → 实体化 → 倒角 → 扭转 → 导出 GLB。

5. 所有脚本可重复执行，输出路径与命名固定：
   - `public/models/spaceyew-page.glb`
   - `public/env/spaceyew-studio.hdr`
6. 不引入第三方模型、HDRI 或贴图。

## 14. 风险与边界

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 透射 + 色散在移动端过重 | 掉帧、发热 | 像素预算、透射降采样、手机降低色散与粒子 |

| 真实数据为空 | 视觉空洞 | 复用现有空状态；不补造内容 |
| 许可与素材 | 合规 | 全部自制；不下载第三方 HDR / 模型 |

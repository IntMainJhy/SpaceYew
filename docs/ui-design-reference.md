# 共享界面设计参考 · 2026-10-30

本轮在既有网站上统一组件与页面节奏，保留 Baskerville / 宋体、黑白控件、SY 图标、白色连续背景和作者独立主题。

## 参考来源

- [UI UX Pro Max](https://www.uupm.cc/)：采用交互反馈、触控尺寸、清晰焦点、深浅色对比度和响应式的质量要求。其样式检索匹配到 Minimalism & Swiss Style；推荐的新字体与蓝色强调色不覆盖用户已有选择。
- [Linear：A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh)：借鉴辅助导航退后、当前任务优先、减少控件轮廓噪声的原则。
- [Curated](https://curated.design/)：参考按页面与组件组织设计案例的方法，用于比较首屏、目录与内容卡片的关系。未复制其视觉资产或品牌。

## 本轮实现

- 共享导航保持单行，当前位置用细线提示；外观入口降低轮廓强度。手机菜单统一宽度、行高、悬停与当前状态，支持 Escape、点外部关闭以及键盘焦点返回。
- 首页保留原有文案和流动背景，加强下载入口尺寸与图标，文字入口使用同一方向图标。社区预览增加真实入口和标题，空状态明确显示现有文案。
- 文档、Skill 和资源目录统一内容宽度、页首层级、筛选项及卡片间距，不添加整页外框。
- 系统默认封面改为中性灰，并集中生成带版本的封面地址，使目录、详情、编辑预览和社区引用同时更新。用户上传封面保持原图。
- 动效集中在导航提示、菜单展开、方向图标反馈与既有图片揭示；新增位移遵守减少动态偏好，正文始终可见。
- 使用现有深浅色语义变量；Skill 搜索框内外使用同一表面色。

## 边界

真实账号、资料、上传、公开状态及作者自定义字体/颜色保持原有行为。本轮是共享界面与内容目录的局部一致性调整，不代表所有作者主题、后台流程或线上部署完成全面审查。

## 验证范围

相关 27 项测试、类型检查和生产构建通过。浏览器核对首页、文档、Skill、博客与社区的代表性页面，覆盖桌面、平板宽度和手机的深浅色；确认搜索、分类、菜单 Escape/点外部关闭、焦点返回及博客无外框工具条。窄屏菜单定位修复后，320px 和 390px 下全部菜单项均位于视口内。验收截图仅保留在忽略的本地 review 目录。

## 首页版式密度修订

用户后续明确指出“排版松散，像没做完”。本次保留字体、配色、文案与功能，收紧首页布局：内容宽度1120px封顶；介绍区与功能区间距减少；介绍文字与预览垂直居中；社区空状态缩小并移除重复图标；博客预览480px封顶；托管代码示意、学习入口及页尾邀请使用更紧凑的内外间距。

1280px宽浏览器中，介绍区由约437px降至335px，首个功能区提前约102px，首页主体由约3291px降至2487px。核对1280、894、390及320px宽度和深浅色，无横向溢出；主要按钮仍约52px高。相关13项测试、类型检查、生产构建和布局扫描通过。本轮只调整首页布局，不扩大此前验证范围。

## 编辑器页首操作栏

针对右上角每个动作都像同一种方框的问题，将操作分为外观与文字版本、查看与分享、保存与发布三组。辅助动作使用无描边图文按钮，组间用留白和细分隔线组织；预览和发布展开时保留按下状态。保存使用实色主按钮，禁用时改为轻灰面，处理中保留文字反馈并显示加载标记。发布采用上传箭头，与外观的日夜图标区分。

手机保留44px按钮高度，预览和发布使用有明确无障碍名称的图标按钮；原文下拉值在320px宽度下完整显示。保存处理函数、快捷键、分享逻辑及发布语义保持原样。浏览器核对分享弹层、预览返回、发布设置开关、文字版本切换，以及1280、894、390、320px布局和深浅色；未修改或保存真实草稿。相关25项测试、类型检查及生产构建通过。

## 画布返回入口

画布页左上角增加箭头与“返回”文字，成员返回 `/blogs`，管理员返回 `/admin`；读取中和读取失败时也提供同一入口。使用现有内部链接和未保存离开确认，保留44px点击高度、深浅色语义颜色与键盘焦点提示。

浏览器确认已保存草稿可返回博客主页，1280px与320px布局和深浅色均正常；未修改真实草稿。新增未保存离开确认测试，覆盖取消离开、确认离开、已保存状态和监听清理；相关16项测试、类型检查及生产构建通过。

后续按用户要求移除画布页首的 SY 品牌图标，标题直接显示“博客画布”；独立返回入口、账号与保存状态保留。此调整只影响编辑器页首，不改变网站其他位置的品牌图标。

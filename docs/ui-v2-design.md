# UI v2：蓝色创作者展示实验

本版位于 `design/ui-v2`。旧版继续保存在 `main` 的 `c5fe124`，并有 `ui-baseline-2026-10-30` 标签；本轮不合并主分支、不代表正式部署。

用户已确认：首页重点为创作者作品与个人主页，品牌也可重新探索；视觉参考为 [Ego Lite](https://lite.ego.app/)。参考的是海军蓝至冰蓝的空间光场、清透弧面、紧凑导航、现代无衬线与展示窗口的组织方式。没有复制其标识、图片、文案、客户名单或性能数字。

## 当前实现

- 首页使用原生 WebGL 光场与大弧面，清晰展示真实公开主页、作品和创作入口；作品／关于我页签支持点击、方向键及 Home/End。
- 展示资料从现有审核后的公开接口读取，尊重隐藏作品栏目，使用实际封面。无图片的作品直接以项目名称排版，不补造人物、作品或成绩。
- 首屏之后为真实作品、公开主页、社区／文档／Skill 入口与创建／客户端下载，保留实际路由和现有登录、保存、审核流程。
- 品牌改为原创双折面开放窗口。导航使用透明符号，favicon、PNG、Apple icon 与符号从同一 SVG 派生并使用缓存版本。仅新增精确的公开品牌资产后台白名单。
- 公共界面使用本地 DM Sans 与系统中文回退，许可保留在 `public/fonts/dmsans-OFL.txt`；作者自选字体、颜色、页面排版及编辑内容仍有独立作用域。
- 浅色正文画布为 `#eef3f9`，深色为 `#101a31`；公共页级容器继续透明。展示窗口的辅助文字使用独立深蓝色，避免半透明纸面在深色环境下失去对比。

## 动态与回退

光场以约 30fps 绘制上限运行，桌面 DPR 不高于 1.5，手机不高于 1.25。离开视口、切到后台、打印或启用减少动态时暂停；减少动态仍保留完整静态首帧。WebGL 不可用或上下文丢失时显示父级渐变，文字与操作不受影响。卸载会取消动画并释放 GPU、观察器和事件监听。

## 范围

这是首页与公共导航／控件的第一版风格实验，编辑器业务、账号、真实资料、上传文件与客户端源码均不在改写范围。角色 IP 仍留在网站外归档。视觉截图、原站参考与复核记录只保存在被忽略的本地 review 目录，不纳入网站提交。

## 验证

相关 17 项测试、类型检查与生产构建通过，涵盖公开作品投影、隐藏栏目、品牌资产与后台白名单、光场生命周期及回退、外观和既有阅读／下载／导航行为。浏览器核对 1440px、390px、320px、桌面深浅色、展板页签键盘交互与减少动态暂停。独立复核指出的窄屏页首溢出、语言下拉底色和展板辅助文字对比度已修复并复核通过；这只覆盖本轮首页与命名问题，不代表全站或编辑器完成全面审查。

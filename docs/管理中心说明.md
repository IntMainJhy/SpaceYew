# SpaceYew 管理中心

[English](administration.en.md) | **简体中文**

更新：2026-10-20。管理中心位于同一网站的`/admin`，复用既有账号、API和服务端权限；无需另建网站、域名或重复注册管理员。当前为开发版本；部署与许可范围见[网站说明](../README.zh-CN.md)。

## 进入与账号

| 身份 | 入口与范围 |
| --- | --- |
| 站长owner | `/admin`，站点内容/资料/设置/分类/文件/统计、成员与治理 |
| 审核员reviewer | `/admin/community`，获准的投稿/评论/展板审核和普通举报；无站长总览和原内容管理权限 |
| 普通成员member | `/workspace/*`本人工作台，不能读取owner管理页/API |

已登录时直接打开`/admin`，未登录可从`/login?next=/admin`使用原有站长账号。没有通用正式密码；首次初始化凭据在实际APP_DATA_DIR的`initial-admin.txt`，修改密码后该文件删除。不要把实际凭据写入文档或截图。

本地3010可显式使用普通演示成员免登录，它不会变成站长；需要在登录入口换用已有站长身份。文档、UI开发和隔离截图均未创建或提权真实账号。

## 当前页面

总览展示真实内容/成员/展板/文件存储、待审队列、最近编辑和服务状态。待办跳转投稿、评论、展板或举报队列；最近编辑进入当前记录。其他入口包括站长作品/手记/资源、profile、settings、taxonomy、files、trash、statistics和owner专用logs。

网站设置维护品牌/摘要/分享封面、附加简历PDF、最多5项顶部广告/推荐及每系统HTTPS安装包地址和版本。文件页显示上传任务、文件引用、下载和未引用删除；回收站恢复为草稿；统计按所选日期读取真实数据。

社区治理保留固定快照、version/revision、领取人、自审/资格/冻结校验、显式核查和理由。权利通知/申诉及完整私密材料限负责人，结案不自动解冻或恢复。原内容管理和后台URL存在都不改变这些权限。

原站长项目/文章/资源的公开详情投诉自动关联固定公开快照；旧工单由owner搜索已存在公开版的内容、提供依据后关联。详情显示当前内容状态/revision与涉事快照，资源附件下载、类型/版本/目标/来源URL和历史许可（如有）均来自固定快照。暂停/下架、解除本案限制及显式复核恢复是独立动作；过期revision、其他有效冻结、回收站或快照不符会阻止恢复，不能发布私稿。

统一管理日志`/admin/logs`继续使用community_audit，按站点/个人空间/社区、操作人、动作、对象和日期筛选，50条分页；仅owner可读，reviewer与member不能因知道URL而访问。内容/配置/分类仅记录变化字段名及必要元数据，关键变更与审计同事务；不记录密码、凭据、登录邮箱或完整内容/设置值。个人成员文件入口为`/workspace/files`，显示本人文件、用量、引用、下载/删除及未完成上传；存在引用时禁删且服务端409。

## 服务状态与交付边界

“演示/标准环境”“社区仅本机/暂停/关闭”“邮件capture/SMTP/未配置”“下载地址是否配置”仅描述应用配置。capture不外发邮件；SMTP齐全不等于真实投递成功；下载URL齐全不证明二进制可安装，也不认证生产就绪。

macOS与Windows客户端源码及安装包不在本网站仓库发布。网站仅保留外部下载地址配置，客户端的发行与使用权限不由本仓库许可授予。

真实SMTP、正式部署、备份调度/告警和公网全流程仍须在目标环境独立验收。

# Bundled typefaces

These font files are self-hosted. Each family retains its accompanying SIL Open Font License.

New personalization faces are sourced from the [Google Fonts repository](https://github.com/google/fonts):

- [ZCOOL XiaoWei](https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei), `zcoolxiaowei-OFL.txt`
- [ZCOOL KuaiLe](https://github.com/google/fonts/tree/main/ofl/zcoolkuaile), `zcoolkuaile-OFL.txt`
- [Ma Shan Zheng](https://github.com/google/fonts/tree/main/ofl/mashanzheng), `mashanzheng-OFL.txt`
- [Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader), `newsreader-OFL.txt`
- [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans), `dmsans-OFL.txt`

Downloaded 2026-10-25. WOFF2 files are lossless web-container conversions using fontTools and Brotli, without changing glyphs. Chinese families are scoped to CJK Unicode ranges in CSS so a selected Latin family can be paired independently. Font downloads happen only when a face is used; `font-display: swap` keeps text visible during loading. Missing glyphs fall back to device fonts.

Previously bundled Inter, Geist Mono, and Cormorant Garamond retain their individual license files.
